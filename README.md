# Minecraft World & Modpack Data

Backup repository for Minecraft Fabric worlds, mods, configurations, shaders, and resource packs.

## Contents
- **`saves/`**: World saves (including `ABIBO`)
- **`mods/`**: Fabric mod jars
- **`config/`**: Mod configuration files
- **`shaderpacks/`**: Shader packs (Complementary Unbound, etc.)
- **`resourcepacks/`**: Texture & animation packs
- **`options.txt`**: Game video, audio, and control options
